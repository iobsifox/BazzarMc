# BazzarMc

**پل اتصال فروشگاه ووکامرس به سرور ماینکرافت — کاملاً فارسی و راست‌به‌چپ**

سبد خرید و صفحهٔ پرداخت اختصاصی فارسی، ورود با رمز یک‌بارمصرف (داشبورد / ایمیل / پیامک)، کد اتصال ۵ دقیقه‌ای، تحویل خودکار آیتم‌ها و رتبه‌ها در بازی.

> توسعه‌دهنده: **Obsifox Studio** — پروانه: **GPL-2.0-or-later** — نسخهٔ **1.0.0**

این مخزن عمومی فقط **خروجی‌های آمادهٔ نصب** و مستندات را منتشر می‌کند (مخزن سورس، خصوصی است).

## نصب در ۵ گام

**۱) افزونهٔ وردپرس**

پیشخوان ← افزونه‌ها ← افزودن ← بارگذاری افزونه ← فایل `bazzarmc-1.0.0.zip` ← فعال‌سازی.

**۲) تنظیم توکن و سرور**

پیشخوان ← **BazzarMc** ← تب *اتصال سرور*: نام و آی‌پی سرور، سیاست نام کاربری (پریمیوم/هر نام) و **توکن API** را کپی کنید.

**۳) پلاگین ماینکرافت**

```bash
cp BazzarMC-1.0.0.jar /path/to/server/plugins/
# یک‌بار سرور را اجرا کنید تا plugins/BazzarMC/config.yml ساخته شود
```

در `config.yml`:

```yaml
api:
  base-url: "https://yoursite.com"
  token: "<توکن از تب اتصال سرور>"
  verify-ssl: true        # برای گواهی خودامضا: false

store:
  name: "فروشگاه من"      # {store}
  ip: "play.yoursite.com" # {ip}

command:
  name: "mclink"          # نام دستور دلخواه شما
  aliases: [bazzar, link]
  admin-name: "bmc"
```

سپس محصولات را در بخش `products` تعریف کنید و در کنسول `bmc reload` و `bmc ping` را بزنید.

**۴) برگه‌ها**

پیشخوان ← BazzarMc ← تب *ابزارها* ← «ساخت خودکار صفحه‌ها» → برگه‌های اتصال، ورود، سبد خرید و پرداخت ساخته می‌شوند
(شورت‌کدها: `[bazzarmc]`، `[bazzarmc_login]`، `[bazzarmc_cart]`، `[bazzarmc_checkout]`).

**۵) پیامک و روش‌های تأیید**

تب *پیامک*: کانال ارسال را انتخاب کنید (پل **EZ-Login** یا فیلتر `bmc_sms_send_text` برای سرویس دلخواه) و «ارسال پیامک آزمایشی» را بزنید؛ تب *ورود و عضویت*: روش‌های تأیید (داشبورد / ایمیل / پیامک) و **کارت حساب کاربری** را تنظیم کنید؛ تب *محصولات*: نقش و **مدت اعتبار رنک** هر محصول را تعیین کنید.

## قابلیت‌ها

### سه روش تأیید هویت (هرکدام مستقل قابل خاموش/روشن‌کردن)

| روش | چگونه | هزینه |
|---|---|---|
| **داشبورد / پنل کاربری** | کد در همان صفحهٔ ورود و پنل حساب کاربری نمایش داده و خودکار پر می‌شود (+ ویجت پیشخوان مدیر برای پشتیبانی) | **رایگان** |
| **ایمیل** | کد به ایمیل ثبت‌شده در حساب کاربر فرستاده می‌شود | رایگان |
| **پیامک** | ارسال از راه پل **EZ-Login** (`ez_send_sms()`) یا فیلتر `bmc_sms_send_text` برای هر سرویس پیامکی دلخواه | بر اساس تعرفهٔ سرویس شما |

### حساب کاربری و رنک‌ها

* **کارت داشبورد حساب کاربری** — در صفحهٔ «حساب کاربری» ووکامرس، به‌جای متن پیش‌فرض، کارت اختصاصی BazzarMc نمایش داده می‌شود:
  نام واقعی کاربر (نام و نام خانوادگی)، ایمیل، موبایل و تعداد سفارش‌ها؛ جعبهٔ **اکانت ماینکرافت** با آواتار، نام کاربری، UUID و تاریخ اتصال — و اگر حساب هنوز متصل نباشد، همان‌جا دکمهٔ **«اتصال اکانت ماینکرافت»** قرار می‌گیرد؛ به‌همراه فهرست **رنک‌های خریداری‌شده**.
* **زمان باقی‌ماندهٔ رنک** — برای هر رنک، مدت باقی‌مانده (روز و ساعت)، تاریخ انقضای شمسی و نوار پیشرفت نمایش داده می‌شود؛ رنک‌های دائمی با نشان «دائمی» مشخص‌اند و رنک‌هایی که کمتر از ۳ روز اعتبار دارند هشدار می‌گیرند.
* **رنک زمان‌دار** — در تب *محصولات* مدت اعتبار نقش هر محصول/نسخه را به «روز» تعیین می‌کنید (`۰` = دائمی) و یک «اعتبار پیش‌فرض» هم برای همهٔ محصولات وجود دارد. تمدید خرید، اعتبار را به زمان باقی‌مانده اضافه می‌کند.
* **بازپس‌گیری خودکار** — زمان‌بند ساعتی، رنک‌های منقضی را از کاربر می‌گیرد (نقش‌های محافظت‌شده هرگز گرفته نمی‌شوند) و رویداد را لاگ می‌کند.
* **آیکون‌های Material Symbols گوگل** — هیچ ایموجی‌ای در رابط وجود ندارد؛ ۱۰۷ آیکون واقعی متریال به‌صورت SVG درون‌خطی (بدون فونت و بدون درخواست خارجی) در پنل مدیریت، سبد خرید، چک‌اوت، پنل کاربری و کارت حساب کاربری استفاده می‌شود.

### سبد خرید و پرداخت

* **سبد اختصاصی فارسی/RTL** (`[bazzarmc_cart]`) با تصویر آیتم‌ها، تغییر تعداد، حذف، کد تخفیف، جمع کل و **پرداخت در همان صفحه**.
* **گیت سبد خرید** — تا اتصال اکانت ماینکرافت، دکمهٔ «ادامهٔ فرآیند خرید / پرداخت» غیرفعال می‌ماند و پیام راهنما + دکمهٔ «اتصال اکانت» نمایش داده می‌شود.
* **چک‌اوت اختصاصی** روی موتور ووکامرس (سبد، سفارش‌ها و درگاه‌های پرداخت دست‌نخورده می‌مانند).
* **چک‌اوت بلوکی ووکامرس**: اجبار به چک‌اوت کلاسیک / تزریق فیلدهای ماینکرافت در بلوک / فقط هشدار به مدیر.
* **فارسی‌سازی کامل فیلدها**: برچسب و placeholder همهٔ فیلدها، فهرست استان‌های ایران، نام فارسی کشورها، قالب آدرس ایرانی و ارقام فارسی (اختیاری).

### اتصال و تحویل

* **کد اتصال ۵ دقیقه‌ای** در پنل کاربری (هش‌شده در دیتابیس) + اتصال از داخل بازی با `/mclink <کد>`.
* **اتصال با رمز یک‌بارمصرف از داخل بازی**: `/mclink phone <شماره> [کد]` و `/mclink mail <ایمیل> [کد]`.
* **شناسهٔ تحویل محصول با ۵ حالت**: نام محصول، شناسهٔ محصول (ID)، **نامک (slug)**، کد کالا (SKU) یا متن دلخواه.
  مثال: نمایش «کوین ۱۰۰» با نامک `gold_pack_2` — پلاگین ماینکرافت با هر دو کلید محصول را پیدا می‌کند.
* **صف تحویل** با ۴ وضعیت، **نقش کاربری به تفکیک محصول**، **هدیه‌دادن خرید** به بازیکن دیگر، انقضای خودکار و خروجی CSV.
* **بازپس‌گیری نقش‌ها** هنگام استرداد (refund) یا لغو سفارش — نقش‌های محافظت‌شده (مدیر/ویرایشگر/نویسنده/مدیر فروشگاه) هرگز گرفته نمی‌شوند.
* **بررسی نام کاربری مویانگ** برای اکانت‌های پریمیوم.

### هماهنگی و سازگاری

* **EZ-Login (ایزی‌لاگین)** — بدون هیچ دست‌کاری در آن افزونه: خواندن کلیدهای متای موبایل از فیلتر `ez_login_phone_meta_keys`، تشخیص آماده بودن سرویس پیامک و ارسال با تابع خودِ ایزی‌لاگین (`ez_send_sms()`). سرویس‌های پیامکی جدیدِ ایزی‌لاگین هم به‌صورت خودکار دنبال می‌شوند.
* **Digits، داروازه، WP-SMS و پیامیتو** — شناسایی و بازیابی شمارهٔ موبایل ذخیره‌شده (کلیدهای متا قابل تنظیم + ابزار اسکن و همگام‌سازی).
* **استثنای خودکار از کش** — LiteSpeed Cache، WP Rocket، W3 Total Cache، WP Fastest Cache، WP Super Cache و **Cloudflare** (پاک‌سازی کش + ساخت/به‌روزرسانی Cache Rule از راه API). از نشت کد یکبارمصرف یک کاربر به کاربر دیگر جلوگیری می‌کند.
* **مهاجرت از نسخهٔ قدیمی** (`storelinkformc`) و **سازگاری معکوس REST**.
* **تقویم شمسی**، لاگ رویدادها، زمان‌بند نگهداری ساعتی، محدودیت نرخ و nonce در همهٔ فرم‌ها.

### سمت ماینکرافت

* **نام دستور و نام‌های جایگزین کاملاً قابل تغییر** توسط مدیر (`command.name` / `command.aliases` / `command.admin-name`) — ثبت در زمان اجرا، بدون ویرایش `plugin.yml`.
* **کلید `api.verify-ssl`** برای سرورهای با گواهی خودامضا (هماهنگ با `ssl_verify` در پنل وردپرس).
* متغیرهای `{store}` `{store_url}` `{ip}` `{server}` `{cmd}` `{admin_cmd}` `{player}` `{uuid}` `{key}` `{slug}` `{sku}` در همهٔ پیام‌ها و دستورهای کنسول.
* تحویل **آیتم** (material/amount/name/lore)، **دستور کنسول** (LuckPerms / EssentialsX / Economy) یا هر دو با هم.
* **تطبیق ۵ مرحله‌ای محصول**: شناسهٔ تحویل پنل ← نام ← شناسهٔ نسخه ← شناسهٔ محصول ← نامک ← SKU.
* همهٔ درخواست‌های شبکه **ناهمگام** (بدون لگ) و بایت‌کد **Java 8** (اجرا روی Java 8 تا 21).

## مسیرهای REST

```text
https://yoursite.com/wp-json/bazzarmc/v1/
  ping              GET|POST   سلامت اتصال
  link/redeem       POST       استفاده از کد پنل کاربری
  link/request      POST       درخواست رمز یک‌بارمصرف (sms / email / dashboard)
  link/verify       POST       تأیید رمز و اتصال
  player            GET        وضعیت بازیکن
  deliveries        GET        صف تحویل‌های در انتظار
  deliveries/mark   POST       ثبت تحویل
  unlink            POST       لغو اتصال
```

احراز هویت: هدر `X-BMC-Token` (یا `Authorization: Bearer …` یا پارامتر `token`).

## عیب‌یابی سریع

| مشکل | اولین اقدام |
|---|---|
| «ارتباط با سایت برقرار نشد» در بازی | `bmc ping` در کنسول + تب *ابزارها* ← «تست اتصال» |
| پیامک ارسال نمی‌شود | تب *پیامک* ← «ارسال پیامک آزمایشی»، بررسی آماده بودن EZ-Login یا فیلتر `bmc_sms_send_text`، و دیدن پیام خطا در تب *ابزارها* ← لاگ رویدادها |
| آیتم تحویل داده نمی‌شود | هم‌خوانی کلید `products` در `config.yml` با «شناسهٔ تحویل» محصول در تب *محصولات* |
| دکمهٔ پرداخت در سبد غیرفعال است | رفتار عمدی «گیت سبد خرید» — کاربر باید اکانت ماینکرافت را متصل کند |
| کد یکبارمصرف به کاربر دیگری نمایش داده می‌شود | کش صفحه فعال است — تب *اتصال سرور* ← «استثنا از کش» + تب *ابزارها* ← «پاک‌سازی کش» |
| خطای گواهی SSL در پلاگین ماینکرافت | `api.verify-ssl: false` در `config.yml` (فقط برای گواهی خودامضا) |
