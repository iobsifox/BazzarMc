# BazzarMc

## Summary

BazzarMc connects a WooCommerce store to a Minecraft server and automates account linking, purchases and in-game delivery.

---

## Description

The product provides a Persian and RTL-ready commerce flow for Minecraft communities. It includes a custom cart and checkout experience, one-time-password authentication through dashboard, email or SMS, five-minute connection codes, and automated delivery of ranks and items.

The implementation source is maintained privately. This public repository contains product information and published packages.

---

## Version

- Current public version: `2.0.3`
- Release channel: `Beta`
- Test status: Testing version; not classified as stable
