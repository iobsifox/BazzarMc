# BazzarMc

**پل اتصال فروشگاه ووکامرس به سرور ماینکرافت — کاملاً فارسی و راست‌به‌چپ**

سبد خرید و صفحهٔ پرداخت اختصاصی فارسی، کد اتصال ۵ دقیقه‌ای با تأیید داشبوردی/ایمیلی/پیامکی، تحویل خودکار آیتم‌ها و رتبه‌ها در بازی، **منوی دریافت آیتم‌ها با کد خرید**، **سلسله‌مراتب رنک‌ها** و **سامانهٔ تیکت پشتیبانی**.

> توسعه‌دهنده: **Obsifox Studio** — پروانه: **GPL-2.0-or-later** — نسخهٔ **1.2.0**

این مخزن عمومی فقط **خروجی‌های آمادهٔ نصب** و مستندات را منتشر می‌کند (مخزن سورس، خصوصی است).

> **تغییر مهم در ۱.۲.۰:** ورود/عضویت با رمز یک‌بارمصرف موبایل از این افزونه **حذف شد**؛ مسئولیت ورود کاربر با افزونه‌های تخصصی سایت (مثل EZ-Login) است. رمز یک‌بارمصرف در BazzarMc فقط برای **لینک‌کردن اکانت ماینکرافت به حساب کاربری** استفاده می‌شود.

## نصب در ۶ گام

**۱) افزونهٔ وردپرس**

پیشخوان ← افزونه‌ها ← افزودن ← بارگذاری افزونه ← فایل `bazzarmc-1.2.0.zip` ← فعال‌سازی.

**۲) تنظیم توکن و سرور**

پیشخوان ← **BazzarMc** ← تب *اتصال سرور*: نام و آی‌پی سرور، سیاست نام کاربری (پریمیوم/هر نام) و **توکن API** را کپی کنید.

**۳) پلاگین ماینکرافت**

```bash
cp BazzarMC-1.2.0.jar /path/to/server/plugins/
# یک‌بار سرور را اجرا کنید تا plugins/BazzarMC/config.yml ساخته شود
```

در `config.yml`:

```yaml
api:
  base-url: "https://yoursite.com"
  token: "<توکن از تب اتصال سرور>"
  verify-ssl: true        # برای گواهی خودامضا: false

store:
  name: "فروشگاه من"      # {store}
  ip: "play.yoursite.com" # {ip}

command:
  name: "mclink"          # نام دستور دلخواه شما
  aliases: [bazzar, link]
  admin-name: "bmc"

ranks:
  sync-to-site: true      # ارسال تعریف رنک‌ها و زمان باقی‌مانده به سایت
  report-interval-minutes: 60
  list:
    vip:   { name: "رتبهٔ VIP",  level: 1, role: "vip",     days: 30 }
    vip+:  { name: "رتبهٔ VIP+", level: 2, role: "vipplus", days: 30 }
    legend:{ name: "رتبهٔ لجند", level: 3, role: "legend",  days: 0 }

gui:
  enabled: true           # منوی دریافت آیتم‌ها با /mclink gui
  reminder-enabled: true  # یادآوری آیتم‌های تحویل‌گرفته‌نشده
```

سپس محصولات را در بخش `products` تعریف کنید و در کنسول `bmc reload`، `bmc ping` و `bmc syncranks` را بزنید.

**۴) برگه‌ها**

پیشخوان ← BazzarMc ← تب *ابزارها* ← «ساخت خودکار صفحه‌ها» → برگه‌های اتصال، سبد خرید، پرداخت و تیکت پشتیبانی ساخته می‌شوند
(شورت‌کدها: `[bazzarmc]`، `[bazzarmc_cart]`، `[bazzarmc_checkout]`، `[bazzarmc_tickets]`). یک‌بار هم *تنظیمات ← پیوندهای یکتا ← ذخیرهٔ تغییرات* را بزنید تا منوهای «حساب کاربری» ثبت شوند.

**۵) محصولات، نقش‌ها و رنک‌ها**

تب *محصولات و نقش‌ها*: محصولات قابل تحویل را انتخاب کنید و برای هر محصول **نقش کاربری**، **شناسهٔ تحویل**، **مدت اعتبار رنک** و **سطح رنک** را تعیین کنید. کلیدهای «جلوگیری از خرید رنک پایین‌تر» و «پنهان‌کردن رنک‌های پایین‌تر» سلسله‌مراتب را فعال می‌کنند.

**۶) پیامک، روش‌های تأیید و تیکت‌ها**

تب *پیامک*: کانال ارسال را انتخاب کنید (پل **EZ-Login** یا فیلتر `bmc_sms_send_text` برای سرویس دلخواه) و «ارسال پیامک آزمایشی» را بزنید؛ تب *تأیید و حساب کاربری*: روش‌های تأیید لینک‌کردن (داشبورد / ایمیل / پیامک) و **کارت حساب کاربری** را تنظیم کنید؛ تب *تیکت‌ها*: سامانهٔ تیکت، دسته‌ها، ایمیل‌های اطلاع‌رسانی و برگهٔ تیکت‌ها.

## قابلیت‌ها

### سه روش تأیید برای لینک‌کردن اکانت (هرکدام مستقل قابل خاموش/روشن‌کردن)

| روش | چگونه | هزینه |
|---|---|---|
| **داشبورد / پنل کاربری** | کد در همان پنل اتصال و پنل حساب کاربری نمایش داده و خودکار پر می‌شود (+ ویجت پیشخوان مدیر برای پشتیبانی) | **رایگان** |
| **ایمیل** | کد به ایمیل ثبت‌شده در حساب کاربر فرستاده می‌شود | رایگان |
| **پیامک** | ارسال از راه پل **EZ-Login** (`ez_send_sms()`) یا فیلتر `bmc_sms_send_text` برای هر سرویس پیامکی دلخواه | بر اساس تعرفهٔ سرویس شما |

### رنک‌ها و سلسله‌مراتب (جدید در ۱.۲.۰)

* **منبع تعریف رنک‌ها، پلاگین ماینکرافت است** — بخش `ranks.list` در `config.yml` (کلید، نام، `level`، `role`، `days`) به‌صورت دوره‌ای به سایت ارسال می‌شود و در تب *محصولات و نقش‌ها* نمایش داده می‌شود؛ «سطح» تعیین‌شدهٔ دستی در پنل بر آن اولویت دارد.
* **جلوگیری از خرید رنک پایین‌تر** — کاربری که رنک سطح بالاتر دارد، رنک‌های پایین‌تر را **نمی‌بیند**، نمی‌تواند آن‌ها را به سبد اضافه کند و اگر در سبد باشند **پرداخت مسدود** می‌شود و پیام راهنما نمایش داده می‌گردد.
* **همگام‌سازی زمان باقی‌مانده از بازی به سایت** — هر `ranks.report-interval-minutes` دقیقه (پیش‌فرض ۶۰) رنک‌های فعال بازیکنان آنلاین گزارش می‌شود؛ رنک‌های حذف‌شده خودکار بازپس گرفته می‌شوند. اگر **LuckPerms** نصب باشد، انقضای واقعی گروه خوانده می‌شود و در غیر این صورت از `plugins/BazzarMC/ranks.yml` استفاده می‌گردد.
* **تجمیع اعتبار** — خرید چند دوره پشت‌سرهم، مدت اعتبار را به زمان باقی‌مانده اضافه می‌کند.
* **رنک زمان‌دار و بازپس‌گیری خودکار** — مدت اعتبار نقش هر محصول/نسخه به «روز» (`۰` = دائمی)؛ زمان‌بند ساعتی رنک‌های منقضی را می‌گیرد و با استرداد (refund) یا لغو سفارش هم نقش‌ها بازپس گرفته می‌شوند (نقش‌های محافظت‌شده هرگز).
* **کارت داشبورد حساب کاربری** — نام واقعی کاربر، ایمیل، موبایل و تعداد سفارش‌ها؛ جعبهٔ **اکانت ماینکرافت** با آواتار، نام کاربری، UUID و تاریخ اتصال (و دکمهٔ «اتصال اکانت ماینکرافت» وقتی هنوز متصل نیست)؛ فهرست **رنک‌های خریداری‌شده** با زمان باقی‌مانده، تاریخ انقضای شمسی و نوار پیشرفت؛ به‌همراه میان‌بر **تیکت پشتیبانی** و شمارندهٔ تیکت‌های باز/پاسخ‌داده‌شده.

### سامانهٔ تیکت پشتیبانی (جدید در ۱.۲.۰)

* **کاملاً مستقل** با دو جدول اختصاصی (`bmc_tickets` و `bmc_ticket_messages`) و **تب «تیکت‌ها»** در پیشخوان.
* کاربر دربارهٔ **محصول خریداری‌شده** تیکت می‌زند؛ فهرست محصولات از سفارش‌های خودِ او ساخته می‌شود (قابل اجباری‌کردن).
* گفت‌وگوی رشته‌ای با وضعیت (باز / پاسخ داده شد / در انتظار شما / بسته)، اولویت (کم / معمولی / زیاد / فوری) و دسته (محصول، تحویل، رنک، پرداخت، حساب کاربری، سایر).
* شمارهٔ پیگیری خوانا مثل `BMC-00018`، جست‌وجو و فیلتر در پنل مدیریت، **یادداشت داخلی** کارکنان (فقط برای مدیران دیده می‌شود)، تغییر وضعیت/اولویت و حذف تیکت.
* دسترسی از سه راه: منوی «تیکت پشتیبانی» در **حساب کاربری ووکامرس**، شورت‌کد `[bazzarmc_tickets]` و تب پیشخوان.
* **ایمیل اطلاع‌رسانی دوطرفه** (تیکت جدید و پاسخ کاربر به مدیر؛ پاسخ پشتیبانی و بستن تیکت به کاربر) با آدرس گیرندهٔ قابل تنظیم.
* محدودیت «حداکثر تیکت باز»، کنترل بستن/بازکردن توسط کاربر و صفحه‌بندی؛ استثنا از کش صفحه‌ها.

### منوی دریافت آیتم‌ها در بازی (جدید در ۱.۲.۰)

* با `/mclink gui` یک منوی صندوقچه‌ای باز می‌شود که در آن **هر خرید یک آیتم کاغذی با نام «کد خرید»** است (پیش‌فرض `شمارهٔ سفارش-شناسهٔ ردیف`، مثال `1042-18`).
* **کلیک روی همان آیتم = تحویل همان خرید** (آیتم‌ها و دستورهای کنسول) و ثبت «تحویل‌شده» در سایت؛ هیچ خرید دیگری تحویل داده نمی‌شود.
* صفحه‌بندی، دکمه‌های بازخوانی/بستن و مادهٔ پرکننده — همه در `gui.*` قابل تغییر (نام و توضیحات آیتم‌ها هم با متغیرها).
* **یادآوری قابل تنظیم** برای آیتم‌های تحویل‌گرفته‌نشده (`gui.reminder-message` هر `gui.reminder-interval-seconds` ثانیه) و **پیام تحویل قابل تنظیم** (`delivery.success-message`).
* `/mclink rank` رنک فعلی، سطح و زمان باقی‌مانده را نشان می‌دهد؛ `/bmc gui [بازیکن]` منو را برای مدیر باز می‌کند.

### سبد خرید و پرداخت

* **سبد اختصاصی فارسی/RTL** (`[bazzarmc_cart]`) با تصویر آیتم‌ها، تغییر تعداد، حذف، کد تخفیف، جمع کل و **پرداخت در همان صفحه**.
* **گیت سبد خرید** — تا اتصال اکانت ماینکرافت، دکمهٔ «ادامهٔ فرآیند خرید / پرداخت» غیرفعال می‌ماند و پیام راهنما + دکمهٔ «اتصال اکانت» نمایش داده می‌شود.
* **چک‌اوت اختصاصی** روی موتور ووکامرس (سبد، سفارش‌ها و درگاه‌های پرداخت دست‌نخورده می‌مانند).
* **چک‌اوت بلوکی ووکامرس**: اجبار به چک‌اوت کلاسیک / تزریق فیلدهای ماینکرافت در بلوک / فقط هشدار به مدیر.
* **فارسی‌سازی کامل فیلدها**: برچسب و placeholder همهٔ فیلدها، فهرست استان‌های ایران، نام فارسی کشورها، قالب آدرس ایرانی و ارقام فارسی (اختیاری).

### اتصال و تحویل

* **کد اتصال ۵ دقیقه‌ای** در پنل کاربری (هش‌شده در دیتابیس) + اتصال از داخل بازی با `/mclink <کد>`.
* **اتصال با رمز یک‌بارمصرف از داخل بازی**: `/mclink phone <شماره> [کد]` و `/mclink mail <ایمیل> [کد]` (برای لینک‌کردن اکانت، نه ورود به سایت).
* **شناسهٔ تحویل محصول با ۵ حالت**: نام محصول، شناسهٔ محصول (ID)، **نامک (slug)**، کد کالا (SKU) یا متن دلخواه.
  مثال: نمایش «کوین ۱۰۰» با نامک `gold_pack_2` — پلاگین ماینکرافت با هر دو کلید محصول را پیدا می‌کند.
* **صف تحویل** با ۴ وضعیت، **نقش کاربری به تفکیک محصول**، **هدیه‌دادن خرید** به بازیکن دیگر، انقضای خودکار و خروجی CSV.
* **بررسی نام کاربری مویانگ** برای اکانت‌های پریمیوم.
* **آیکون‌های Material Symbols گوگل** — هیچ ایموجی‌ای در رابط وجود ندارد؛ ۱۲۴ آیکون واقعی متریال به‌صورت SVG درون‌خطی (بدون فونت و بدون درخواست خارجی).

### هماهنگی و سازگاری

* **EZ-Login (ایزی‌لاگین)** — بدون هیچ دست‌کاری در آن افزونه: خواندن کلیدهای متای موبایل از فیلتر `ez_login_phone_meta_keys`، تشخیص آماده بودن سرویس پیامک و ارسال با تابع خودِ ایزی‌لاگین (`ez_send_sms()`). سرویس‌های پیامکی جدیدِ ایزی‌لاگین هم به‌صورت خودکار دنبال می‌شوند.
* **Digits، داروازه، WP-SMS و پیامیتو** — شناسایی و بازیابی شمارهٔ موبایل ذخیره‌شده (کلیدهای متا قابل تنظیم + ابزار اسکن و همگام‌سازی) و تکمیل خودکار شماره در چک‌اوت.
* **LuckPerms** — خواندن انقضای واقعی گروه‌ها با reflection (بدون وابستگی سخت).
* **استثنای خودکار از کش** — LiteSpeed Cache، WP Rocket، W3 Total Cache، WP Fastest Cache، WP Super Cache و **Cloudflare** (پاک‌سازی کش + ساخت/به‌روزرسانی Cache Rule از راه API) برای صفحه‌های اتصال، چک‌اوت و تیکت‌ها.
* **مهاجرت از نسخهٔ قدیمی** (`storelinkformc`) و **سازگاری معکوس REST**.
* **پنل مدیریت ۱۰ بخشی** با تقویم شمسی، آمار زنده، جست‌وجو، فیلتر، صفحه‌بندی، خروجی CSV، لاگ رویدادها و ابزارهای نگهداری.

### سمت ماینکرافت

* **نام دستور و نام‌های جایگزین کاملاً قابل تغییر** توسط مدیر (`command.name` / `command.aliases` / `command.admin-name`) — ثبت در زمان اجرا، بدون ویرایش `plugin.yml`.
* **دستورهای بازیکن**: `/mclink <کد>`، `status`، `claim`، `gui`، `rank`، `phone`، `mail`. **دستورهای مدیر**: `/bmc version|reload|ping|token|deliveries|unlink|ranks|syncranks|report|gui|products`.
* **کلید `api.verify-ssl`** برای سرورهای با گواهی خودامضا (هماهنگ با `ssl_verify` در پنل وردپرس).
* متغیرهای `{store}` `{store_url}` `{ip}` `{server}` `{cmd}` `{gui_cmd}` `{admin_cmd}` `{player}` `{uuid}` `{key}` `{slug}` `{sku}` `{code}` `{product}` `{order}` `{order_number}` `{rank_level}` `{days}` `{rank_role}` در همهٔ پیام‌ها و دستورهای کنسول.
* تحویل **آیتم** (material/amount/name/lore)، **دستور کنسول** (LuckPerms / EssentialsX / Economy) یا هر دو با هم.
* **تطبیق ۵ مرحله‌ای محصول**: شناسهٔ تحویل پنل ← نام ← شناسهٔ نسخه ← شناسهٔ محصول ← نامک ← SKU.
* همهٔ درخواست‌های شبکه **ناهمگام** (بدون لگ) و بایت‌کد **Java 8** (اجرا روی Java 8 تا 21).

## مسیرهای REST

```text
https://yoursite.com/wp-json/bazzarmc/v1/
  ping                GET|POST   سلامت اتصال
  link/redeem         POST       استفاده از کد پنل کاربری
  link/request        POST       درخواست رمز یک‌بارمصرف (sms / email / dashboard)
  link/verify         POST       تأیید رمز و اتصال حساب
  player              GET        وضعیت بازیکن
  deliveries          GET        صف تحویل‌های در انتظار (+ code, product, rank_level, order_number)
  deliveries/mark     POST       ثبت تحویل
  unlink              POST       لغو اتصال
  products            GET        فهرست محصولات، رنک‌ها و وضعیت سامانهٔ رنک
  ranks/definitions   POST       دریافت تعریف رنک‌ها از پلاگین ماینکرافت
  ranks/report        POST       گزارش زمان باقی‌ماندهٔ رنک یک بازیکن
  ranks/status        GET        وضعیت رنک‌های یک بازیکن
```

احراز هویت: هدر `X-BMC-Token` (یا `Authorization: Bearer …` یا پارامتر `token`).

## عیب‌یابی سریع

| مشکل | اولین اقدام |
|---|---|
| «ارتباط با سایت برقرار نشد» در بازی | `bmc ping` در کنسول + تب *ابزارها* ← «تست اتصال» |
| پیامک ارسال نمی‌شود | تب *پیامک* ← «ارسال پیامک آزمایشی»، بررسی آماده بودن EZ-Login یا فیلتر `bmc_sms_send_text`، و دیدن پیام خطا در تب *ابزارها* ← لاگ رویدادها |
| آیتم تحویل داده نمی‌شود | هم‌خوانی کلید `products` در `config.yml` با «شناسهٔ تحویل» محصول در تب *محصولات و نقش‌ها* |
| منوی `/mclink gui` خالی است | بازیکن آیتم تحویل‌گرفته‌نشده ندارد (`bmc deliveries <نام>`) یا `gui.enabled: false` است |
| رنک‌ها در پنل سایت دیده نمی‌شوند | `ranks.list` خالی یا `ranks.sync-to-site: false` است؛ `bmc syncranks` را بزنید |
| زمان باقی‌ماندهٔ رنک به‌روز نمی‌شود | بازیکن باید آنلاین باشد؛ برای تست `bmc report <نام>` و بررسی لاگ کانال `rank` در تب *ابزارها* |
| کاربر رنک بالاتر، رنک پایین‌تر را نمی‌بیند | رفتار عمدی سلسله‌مراتب است؛ کلیدهای «پنهان‌کردن» یا «جلوگیری از خرید رنک پایین‌تر» را در تب *محصولات و نقش‌ها* خاموش کنید |
| تیکت‌ها در حساب کاربری دیده نمی‌شوند | تب *تیکت‌ها* ← «فعال‌سازی» + ذخیرهٔ یک‌بارهٔ پیوندهای یکتا |
| ایمیل تیکت ارسال نمی‌شود | کلیدهای «ایمیل به مدیر/کاربر» و آدرس گیرنده در تب *تیکت‌ها*؛ سالم‌بودن `wp_mail` سایت |
| دکمهٔ پرداخت در سبد غیرفعال است | رفتار عمدی «گیت سبد خرید» — کاربر باید اکانت ماینکرافت را متصل کند |
| کد یکبارمصرف به کاربر دیگری نمایش داده می‌شود | کش صفحه فعال است — تب *اتصال سرور* ← «استثنا از کش» + تب *ابزارها* ← «پاک‌سازی کش» |
| خطای گواهی SSL در پلاگین ماینکرافت | `api.verify-ssl: false` در `config.yml` (فقط برای گواهی خودامضا) |
